# 📊 Snapchat Marketing Analytics Dashboard & AI Agent Skill

## 🚀 Overview

This project focuses on analyzing Snapchat marketing campaign performance using **Power BI, Python, and DAX**.

It provides an interactive dashboard to evaluate campaign effectiveness, audience engagement, advertising expenditure, revenue, and return on investment (ROI).

Additionally, the project has been converted into a reusable **AI Agent Skill** and successfully published on the Agensi marketplace, allowing users to perform marketing analytics through their connected AI agents.

🔗 **Live Agensi Skill:** https://www.agensi.io/skills/snapchat-marketing-analytics

## 🗂️ Dataset Information

- **Records:** 10,000
- **Columns:** 22
- **Dataset Type:** Synthetic Snapchat Marketing Dataset

**Note:** The dataset included in this project is synthetic sample data created for demonstration, testing, and analysis purposes. It does not represent actual Snapchat advertising campaign data.
