# 📊 Snapchat Marketing Analytics Dashboard

## Overview

This project presents an interactive Power BI dashboard designed to analyze Snapchat marketing campaign performance.

The dashboard helps marketing teams evaluate campaign effectiveness, audience engagement, advertising spend, revenue, and return on investment through interactive visualizations and KPIs.

## Features

- Executive KPI Dashboard
- Campaign Performance Analysis
- Revenue & Spend Analysis
- Device Performance
- Country-wise Performance
- Monthly Click Analysis
- Interactive Filters
- Professional UI Design

## KPIs

- Total Impressions
- Total Reach
- Total Clicks
- Total Conversions
- Total Spend
- Total Revenue
- ROI
- CTR



## Dataset

- 10,000 Records
- 22 Columns
- Synthetic Snapchat Marketing Dataset
